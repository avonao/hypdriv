Fixes from the live Vercel run (Hobby plan):

- **Tag-revalidated prerenders are `isr`** (ADR 0018): a prerender whose data carries explicit cache tags (`x-next-cache-tags` without the implicit `_N_T_` ones) is regenerated by `revalidateTag()`, so it no longer gets a build-time hash CSP that blocks its regenerated inline scripts. The tags are recorded as `route.prerender.tags`.
- **Purges from Vercel Functions:** `createInstrumentation().register()` registers the Vercel CDN purger, so `revalidateTag()`, `revalidatePath()` and `purgeEdge()` in Route Handlers and Server Actions purge Hypdriv's CDN tags; `path:` tags also purge the CDN's `hyp:path:` tags; the repeat purge runs under the platform `waitUntil`.
- **No hanging fetches:** response body cancels are never awaited (`hypFetch` retries, `enqueue()`'s inline consumer call, cache warming) — Next.js tees `fetch` bodies and such a cancel never settles; `hypFetch`'s timeout and the caller's abort settle each attempt themselves (`E_TIMEOUT`) and late responses are released.
- **Vercel CDN reporting:** pages matched by a policy without a route-header form (`vary`, untranslatable patterns) are reported as `BYPASS` with `x-hypdriv-cache-reason: route-header:<why>`; the build warns for them; `hypdriv audit cache` reports such platform limits as warnings.
- **Jobs:** `jobHandler` reads the secret env names from `security.internalAuth.secretEnv` and `vercel.cronSecretEnv`, and fills the job name and schedule of Vercel Cron calls from the `jobs.cron` entry for the path.
- **Health and vitals:** `/_hypdriv/health` reports `VERCEL_DEPLOYMENT_ID` as `deployment` when Next.js has none and gains a `config store` line (Global Config, Upstash Redis, Workers KV); vitals beacons logged by the proxy carry the visitor's country from edge headers (`HEADER.cacheReason` added).
- **Monorepos:** `doctor`, `analyze` and the audit's secret lookup find a Vercel link at the repository root (the app named as the project's root directory), including the env files `vercel pull` wrote and `.vercel/output`.
