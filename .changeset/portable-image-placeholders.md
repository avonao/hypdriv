Image placeholders without sharp. `generatePlaceholders()` now has a portable engine: PNG (every color type and bit depth, Adam7, `tRNS`), JPEG (baseline and progressive, any chroma subsampling, restart intervals, grayscale, CMYK) and GIF are decoded by built-in TypeScript decoders and area-averaged straight into the placeholder, and WebP/AVIF are read, and WebP written, through the optional `@jsquash/webp` / `@jsquash/avif` WebAssembly codecs. `engine: 'auto'` (default) uses `sharp` when it is installed and the portable engine otherwise instead of skipping, so CI images without native modules produce placeholders; the output is a WebP with sharp or `@jsquash/webp` and a PNG otherwise (`format`). New options `engine`, `format`, `accuracy` (`exact` decodes big JPEGs completely instead of from their DC coefficients), `maxPixels` and `dryRun`; the result gains `engine`, `format` and `unsupported`; the file records engine, format and quality so a run with other settings regenerates. `hypdriv placeholders [--check]` generates them from `images.placeholders` (new keys `engine`, `format`, `quality`, `accuracy`) and gates CI on a stale file. ADR 0026. `hypdriv doctor` gains `images.placeholders` (is the file current, which engine would run, `--fix` regenerates), and `dryRun`/`--check` no longer call WebP and AVIF pictures that no installed codec reads out of date.
