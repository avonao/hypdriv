"@hypdriv/react-router": minor
---

Add `@hypdriv/react-router`: Hypdriv for React Router 8 in framework mode on Cloudflare Workers, Vercel and Node. `hypdriv()` (Vite plugin) serves the config, manifest and the build's prerender token to server code and makes Hypdriv's server entry the SSR entry of Node and Vercel builds; `hypdrivPreset()` finalises the build after prerendering (routes with resource routes as endpoints, per-route assets, hash CSP of prerendered pages, the final manifest patched into the server output, the prerender token erased) and writes Cloudflare `_headers` or the Vercel Build Output (header routes, document rewrites, one traced Node.js function per server bundle with `@vercel/react-router` route settings, Routing Middleware for static paths). The runtime: `hypdrivMiddleware()` for the root route, `createServerEntry()`, `reactRouterWorker()` (Worker shell with assets first, SPA shell, jobs), `hypdriv-react-router-serve` / `serve()` for Node, an `entry.server` with the request's CSP nonce, `hypdrivContext` / `cloudflareContext`, and rules that also cover React Router's `.data` requests.
