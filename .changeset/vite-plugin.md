New package: HypDriv for Vite 8 apps without a server framework (single-page apps and multi-page static sites), and the toolkit every Vite framework integration is built from. `hypdriv()` writes `.hypdriv/manifest.json` from the build (one route per HTML entry, a catch-all shell route for single-page apps, CSP hashes from the final HTML), patches the final manifest into the built server (`patchRuntimeManifest()`), and writes the platform configuration: Cloudflare `_headers` (plus `.assetsignore` for `.vite/`) with `assetsWorker()` from `@hypdriv/vite/worker` in front of the static assets; on Vercel a complete Build Output (static files, header routes, HypDriv's Routing Middleware as a bundled Node.js function, the SPA fallback that never answers `/api/*`, zero-config `api/` functions alongside); on Node `serve()` from `@hypdriv/vite/node` (also `hypdriv serve`). `vite dev` and `vite preview` run the pipeline around documents. Toolkit: `hostPlugin()`, `virtual:hypdriv/config` and `virtual:hypdriv/manifest`, route converters for React Router, TanStack Router, Vue Router and SvelteKit, `finalizeManifest()`, `writeCloudflareStatic()`, `writeVercelStatic()`, `createVercelMiddleware()`.
